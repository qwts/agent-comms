# Owner decisions: proposed private descriptor preimages

These private preimages complete the [preparation](owner-decision-preparation-evidence.md) and [effect record](owner-decision-effect-evidence.md) schemas. This proposed-only specification enables no staging, secret export or production mutation.

## Exact private digest preimages and bounds

All preimages below use the existing canonical JSON encoding, with v:1 and exactly the listed fields. They are private daemon data; only their digests appear in the constant-size evidence. Hash the complete canonical bytes with SHA-256, never an arbitrary caller JSON object. Private bytes, metadata and unsettled evidence count toward the existing 256 MiB daemon staging budget and four-live-stages namespace quota; descriptor retention does not create a quota bypass. File input must be bounded before allocation, with no-follow single-link regular-file checks and unchanged metadata across the read. Overlong or malformed existing state refuses preparation; never truncate or silently start a fresh session. The separate local ceremony remains available as an explicit choice.

| Preimage | Exact schema and bounds |
| --- | --- |
| Destination identity | `{v:1,path,device,inode}`. path is the daemon-selected absolute normalized real path, Unicode scalar/control-free, 1–4096 UTF-8 bytes, with exact path.resolve/realpath equality and no symlink components. device/inode are canonical unsigned decimal strings, `0` or `[1-9][0-9]{0,19}`, numerical value at most 2^64−1, from BigInt stat (no lossy Number conversion). Canonical descriptor cap 8192 bytes. rootDigest and destinationDigest both hash this shape for their respective registered destination/worktree. |
| Working inventory | `{v:1,entries}`; entries is sorted by UTF-8 path bytes, with no duplicate, each exactly `{path,mode,size,digest}`. mode is `040000|100644|100755`, size is safe integer 0–67108864, digest is null for directory (size must0), otherwise SHA-256 of exact file bytes. path is a relative slash-separated scalar/control-free name, no empty/dot/dot-dot/backslash components, 1–4096 UTF-8 bytes and depth≤32. Exclude only existing `.soul-state` and `worktrees` trees without stat/following their contents; include exact soul.json bytes. At most8192 entries, aggregate file bytes64MiB, per file64MiB, canonical descriptor8MiB. Source package reads additionally budget both existing format passes using bot's reader limits, never independently reinterpret packageDigest. |
| Recorded session | `{v:1,harness,sessionId,policy,store}`. harness is codex/opencode/devin/grok; sessionId is scalar/control-free/nonblank, at most4096 UTF-8 bytes, never copied to broker. policy is null for absent legacy policy or read-only/workspace. store is host/soul, with only an absent legacy store normalized to host. An unsupported/malformed stored value refuses. Canonical preimage cap8192 bytes. sessionDigest is null if the selected soul has no active recorded session for that harness; retired history is excluded. |
| Tool-home selection | `{v:1,harness,choice,containment,signIn,hostSignIn,routes}`. harness is codex/opencode/devin/grok; choice null/soul/global; containment soul/shared-host/unsupported; signIn and hostSignIn each present/missing/unknown from existing presence-only checks (never credential bytes). routes is sorted by ASCII env name, at most3 exact `{env,path}` records, env one of CODEX_HOME/XDG_CONFIG_HOME/XDG_DATA_HOME/XDG_CACHE_HOME, path absolute normalized scalar/control-free 1–4096 UTF-8 bytes. No HOME/XDG_STATE_HOME, arbitrary environment or provider secret. Use existing registry/decision functions and retain their actual resolved selection. Canonical cap16384 bytes. |
| Cold state | `{v:1,setting,webhookDigest,resume}` using the exact typed [preparation fields](owner-decision-preparation-evidence.md). beforeDigest, afterDigest and observedDigest hash this selected-soul shape, never the entire global settings/session store. Canonical cap2048 bytes. A setting changed to non-webhook has webhookDigest=null only after secret deletion completes. Resume context binds the soul's current session when current or desired mode is resume; this operation does not create or rewrite the session. |
| Revision observation | `{v:1,head,proposal,working}`. head/proposal use preparation shapes; working null except requested apply=true, then `{rootDigest,inventoryDigest}`. Canonical cap2048 bytes. |
| Webhook | Existing exact normalized `{v:1,key,url}` snapshot from checkWebhook; canonical cap32768 bytes. Only configurationDigest/public validated host are exposed; errors never contain URL/key. |

The 4096-byte preparation/effect and2048-byte reconciliation caps are conservative enforceable encoded-record limits, not inferred from decoded string counts. Private descriptor size is charged separately to staging. No record embeds any private preimage or original action/p1/d1 bytes. Before admission, the lifecycle journal reserves all required capped evidence slots and its separately bounded original action/challenge/token records. A fixture/spec check must enumerate maximal legal evidence forms and prove their canonical byte length fits these caps; this proposal does not yet claim runtime capacity support.
